# Парсер сайтов

## Пример использования

```bash
bin/hexlet-go-crawler https://example.com

# тонкая настройка обхода
bin/hexlet-go-crawler --depth 2 --workers 8 https://example.test
```

## Параметры

- `--depth <int>` - глубина анализа домена (0 - будет произведен анализ только переданного URL)
- `--retries <int>` - количество повторных запросов (для неудачных запросо) (пример: `2`)
- `--delay <string>` - задержка между запросами (пример: `1s`)
- `--timeout <string>` - время ожидания ответа сервера для каждого запроса (пример: `15s`)
- `--rps <int>` - количество запросов в секунду (пример: `4`)
- `--user-agent` - возможность подменить данные об устройстве и браузере c которых выполняется аналитика (пример: `Mozilla/5.0 (X11; Linux x86_64; rv:123.0) Gecko/20100101 Firefox/123.0`)
- `workers` - количество процессов которые конкурентно анализируют ссылки (пример: `4`)

## Команды

- `make build` — собирает CLI-приложение в файл `bin/hexlet-go-crawler`.
- `make test` — запускает все тесты проекта.
- `make run URL=https://example.com` — запускает приложение для указанного URL без предварительной сборки.
